# Last Bell

Last Bell is a time-management coach for students in grades 6 through 9. It helps with the hours after school: games, other screens, homework, and worry about tests.

Bell chats from the grade notes on this site. Answers stay in the browser. There is no account and no API key.

## What you can do

- **Chat** walks through grade, what takes the evening, and a school wake-up time, then gives a night plan.
- **Survey** is seven questions plus a three-question check-in for the week you try the plan.
- **Templates** are cards you can copy: tonight, a homework block, a screen gate, a worry slip, and a weekend hold.
- **Grades** is the research the coach uses, from grade 6 through grade 9.

School-night aims are 9 hours in grades 6 and 7 (the floor of the 9 to 12 hours those students need) and 8 hours in grades 8 and 9 (the short-sleep cutoff at age 13). This is a planning tool, not medical advice.

## Run it locally

```bash
npm install
npm run dev
```

The dev server listens on port 3847.

```bash
npm test
npm run lint
npm run build
```
